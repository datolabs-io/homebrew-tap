# homebrew-tap

Homebrew casks for tools by [MB Datolabs](https://github.com/datolabs-io), published by each project's release.

```bash
brew install --cask datolabs-io/tap/mcp-toolsearch-proxy
brew install --cask datolabs-io/tap/opsy
```

| Cask | Project |
| --- | --- |
| `mcp-toolsearch-proxy` | [datolabs-io/mcp-toolsearch-proxy](https://github.com/datolabs-io/mcp-toolsearch-proxy) |

The casks are generated by GoReleaser; report problems with one in its project's repository.
